# PC Black Box

ダウンロードしたファイルやフォルダーを、実行せずに調べるWindows向け静的調査ツールです。

Marathon Network Blockerの一画面で状態を読み取れる操作感を受け継ぎ、黒・白・黄を基調にしています。管理者権限は要求しません。

## セットアップ

必要なものは次のとおりです。

- Windows 10またはWindows 11
- [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)
- この非公開リポジトリへのアクセス権
- [GitHub CLI](https://cli.github.com/)

PowerShellで次のコマンドを実行します。

```powershell
gh auth login
gh repo clone Elysia20220909/PC-Black-Box
cd PC-Black-Box
dotnet restore
dotnet run --project .\Destiny2BlackBox.csproj
```

すでにGitHubへログインしている場合、`gh auth login`は不要です。

## 使い方

1. `PC Black Box.exe`を起動します。
2. ファイルまたはフォルダーを画面へドロップします。選択ボタンも利用できます。
3. `調査開始`を押します。
4. `概要`で主な所見、`ファイル`で個別情報、`レポート`で匿名化された報告書を確認します。

`JA / EN`で日本語と英語を切り替えられます。選択した言語だけが `%LOCALAPPDATA%\PCBlackBox\settings.json` に保存されます。

## 使いやすさ

- `ファイル`画面では、ファイル名、形式、署名、署名者、入手元、所見をすぐに検索できます。
- `高 / 確認 / 低 / 所見なし`でリスク帯を絞り込み、表示件数と全件数を並べて確認できます。
- `概要`の所見カードをクリックするか、Tabで選んでEnter / Spaceを押すと、根拠となったファイル詳細へ移動します。
- `Ctrl+O`でファイル選択、`Ctrl+Shift+O`でフォルダー選択、`Ctrl+F`で検索、`F5`または`Ctrl+Enter`で調査を開始できます。
- `Ctrl+1 / 2 / 3`で概要・ファイル・レポートを切り替え、調査中の`Esc`で停止できます。
- ファイル詳細の`SHA-256をコピー`と`照会URLをコピー`は、どちらもクリップボードに置くだけです。本体は照会URLを開かず、通信もしません。開くかどうかは操作者の判断で、開けばそのハッシュが相手のサービスに渡ります。なお、クリップボードはこのアプリの外です。Windowsのクリップボード履歴が有効な場合、コピーした文字列はWindows側にも残り、設定によってはMicrosoftアカウントへ同期されます。

## 調べるもの

- SHA-256
- Windowsのローカル信頼情報だけを使う、ネットワーク失効照会なしのAuthenticode署名確認
- Mark-of-the-Web（Internet Zone）と入手元ホスト名
- マジックバイトから見た実ファイル形式
- 二重拡張子、右から左への表示制御、拡張子偽装
- Windowsショートカット: 起動先、引数、作業フォルダー、非表示起動や昇格の指定を、解決も起動もせずに構造から読み取ります
- OLE複合ファイル（インストーラーや旧形式のOffice文書）: 内容から識別して文字列を走査します。内部構造は解析しないため、結果は`INCOMPLETE`になります
- PEアーキテクチャ、製品名、会社名、先頭8MiBから算出するエントロピー
- スクリプト、Windows PE、PDFを明示的な上限内でストリーミング走査し、ダウンロード、永続化、Defender設定変更、プロセス注入、削除などの能力語
- ZIP／Officeパッケージの前置きデータ、内部の二重拡張子、実行要素、マクロ、パストラバーサル、極端な圧縮率
- ZIPの直接項目をディスクへ展開せずストリーミングし、ダウンロード、永続化、Defender設定変更、プロセス注入などの能力語

フォルダー調査は安全のため2,500ファイル、10,000ディレクトリ、深さ128、列挙20,000項目、保持パス情報800万文字、または12GBで打ち切ります。通常ファイルの能力語走査は1ファイル1GiB、1回の調査で合計4GiB、1ファイル60秒、合計180秒が上限です。ZIP内部本文は1項目64MiB、1つのZIPで256MiB、1回の調査で合計1GiBまでです。上限に達した項目が続くかを確認する場合だけ、1項目につき最大1バイトを追加で読みます。圧縮入力は64KiBずつに抑え、30秒／ZIP、120秒／調査の停止判断を各入力読取の前後で確認します。ただし、実行中の1回のローカルOS読取や展開処理そのものを強制中断する保証ではありません。総本文量を実EOFで確定できなかった場合、走査量は表示しても分母を推測せず「合計不明」と表示します。ZIP内部はさらに10,000項目、中央ディレクトリとZIP64終端拡張データ64MiB、中央項目名4,096バイト、入力2GiB、署名確認は300ファイルが上限です。リパースポイントは追跡しません。いずれかの上限、読取失敗、解析時間制限に達した結果は`INCOMPLETE`になり、`CLEAR`とは表示しません。

## 判定について

`CLEAR / LOW / REVIEW / HIGH`は確認の優先順位、`COMPLETE / INCOMPLETE`は調査範囲の完全性です。既知の危険指標と未確認範囲は別々に保持し、たとえば`HIGH+INCOMPLETE`のように同時表示します。いずれもマルウェア判定や安全保証ではありません。

管理用スクリプト、インストーラー、圧縮ツールなどは正当な目的でも警告されることがあります。反対に、静的調査で兆候が見えない未知のコードもあります。署名、入手元、期待した用途、Windows Defenderなど複数の証拠を合わせて判断してください。

## プライバシーと安全境界

- 対象を起動しません。
- ファイルをアップロードしません。
- 自動的なネットワーク通信を行いません。
- プロセス注入、ゲームメモリ読み取り、パケット取得を行いません。
- ファイルの削除、隔離、移動、修復を行いません。
- レポートへ**この環境の**絶対パス、Windowsユーザー名、IPアドレス、Steam ID、認証情報を出しません。ショートカットの起動先と引数のように、調査対象の内部に書かれていた文字列は、判断の根拠として掲載します。
- ただし**レポート自体は取り扱い注意**です。調べたファイル名、入手元ホスト、SHA-256が並ぶため、単体のハッシュより特定力があります。生成物は`.gitignore`で除外していますが、共有する前に中身を確認してください。
- 外部ハッシュ照会やブラウザー起動も行わず、調査中は完全オフラインです。

設計はiOSの安全原則を参考に、最小権限、閉じたデータフロー、明示操作、信頼境界の固定を重視しています。ただし、通常のWindowsデスクトップアプリであり、iOS App Sandboxと同一の隔離を保証するものではありません。

## 深層防御

- アプリ本体の初期化より前に16項目の必須セキュリティ基準を適用し、OSとランタイムの応答から全項目を確認できなければ調査を開始しません。
- 起動後に同じユーザーから新しく要求されるプロセスのメモリ読み取り、書き込み、スレッド挿入、ハンドル複製を拒否します。起動時にDACLを書き換え、`OWNER RIGHTS`で所有者の暗黙のDACL変更権も外します。タスクマネージャー相当の確認と終了は維持します。
- 標準.NETのソケット、名前解決、HTTPなどの通信アセンブリが読み込まれていないことを実行中に確認し、後から読み込まれた場合は利用前にプロセスを停止します。
- 子プロセス生成、レガシー拡張ポイント、非システムフォント、UNC上または低整合性レベルのDLLをOS側で禁止します。
- DEP、ASLR、Control Flow Guard、SEHOPを必須とし、無効ハンドル参照を致命的エラーとして扱います。
- ヒープ破壊を検出した場合、攻撃者が誘導できる状態で処理を続けず、その場でプロセスを終了します。
- P/Invokeと通常のDLL探索をアプリフォルダーとSystem32へ限定し、カレントディレクトリを探索対象から除外します。
- 出荷時のランタイム設定で、Hot Reloadによるメタデータ更新経路とEventSourceのトレース面を無効にします。
- 調査ファイルは再解析ポイントを追跡しないハンドルで開き、読み取り中は置換・書き込みを共有しません。
- 開いたファイルとディレクトリの最終実パスを要求パスと照合し、途中のジャンクション差し替えを拒否します。
- サイズと更新時刻に加え、ボリューム番号と128bitファイルIDを再照合し、同名ファイルへの差し替えを検出します。
- フォルダーの12GB上限は、安全ハンドルから得た実測サイズの累積値でも強制します。
- 列挙・設定保存・レポート保存中は親ディレクトリの削除共有を拒否し、保存先の差し替えを防ぎます。
- 列挙した各ディレクトリのIDと更新時刻を走査後に再確認し、途中で内容が変わった場合は結果を`INCOMPLETE`にします。
- ZIPは標準パーサーへ渡す前にEOCD、ZIP64終端、中央ヘッダー、件数、長さ、境界を検証し、偽終端や中央ディレクトリ洪水をフェイルクローズで拒否します。
- 能力語の検索は重なりを持つチャンクで明示的なバイト・時間上限まで走査し、線形時間の正規表現エンジンと時間上限によって、細工された入力による解析停止を抑えます。上限までに全体を走査できなければ`INCOMPLETE`です。

さらに、リダイレクト信頼の強制、セキュリティドメイン分離、ページ結合の無効化、投機的ストアバイパスの無効化を、OSのビルドとCPUが提供する範囲で適用し、適用後に読み戻して確認します。ハードウェアシャドースタック（CET）は読み取り専用で状態を確認します。提供されない項目は、有効だと仮定せず `unavailable` として表示します。

画面とレポートには、検証済みの必須基準を `16/16` のように表示し、続けてその環境で有効な追加防御の件数を示します。`--security-status` は各項目を1行ずつ出力するため、posture を独立して確認できます。脅威モデル、残る境界、および「検討したうえで採用しなかった防御」とその理由は [`THREAT_MODEL.md`](THREAT_MODEL.md) に記録しています。

これらはAppleが重視するコード信頼と厳格な能力境界を、現在のWindows/WPF構成で実装可能な防御へ置き換えたものです。AppContainerや署名済み配布バイナリを追加するものではありません。

## 現在の制約

- 動的挙動、サンドボックス実行、通信先の実測は行いません。
- WPFプロセス自体はAppContainerではなく、iOS App Sandboxと同じOS隔離ではありません。
- 管理者権限、カーネル、改ざんされたWindows信頼ストアはこの境界の外側です。プロセスの保護が防ぐのは同一ユーザーの通常プログラムであり、特権を持つ相手ではありません。
- プロセスDACLは設定後の新規アクセス要求を制限します。起動元などが設定前から保持しているハンドルを失効させることはできません。
- 通信アセンブリ監視は標準.NET経路の検査であり、AppContainerやWindows Filtering PlatformによるOSレベルの通信能力剥奪ではありません。将来ネイティブ通信コードを追加すればこの監視を迂回できるため、受け入れ対象外です。
- 7-Zip／RARは形式識別までで、内部展開はしません。
- ZIPの直接項目はディスクへ展開せず、上限内で本文の能力語を走査します。これはマルウェア署名エンジンではありません。内部のZIP／7-Zip／RARなどは再帰的に開かないため`INCOMPLETE`です。
- 通常ZIPと安全上限内のZIP64終端レコードは、拡張データを持つ場合も物理境界と相対オフセットから前置き量を復元して本文調査を続けます。前置き部分自体は未解釈なので`INCOMPLETE`です。上限超過など復元できないZIPらしい末尾も、通常ファイルへ戻さず`INCOMPLETE`にします。
- PDF／PE／スクリプトなど別形式とZIPが重なるpolyglotは、主形式を保ったまま両方を調べます。中央ディレクトリの本文サイズは信用せず実際のEOFまで読み、宣言との差は`INCOMPLETE`です。
- 分割ZIP、暗号化された中央ディレクトリ、曖昧な複数EOCDは内部確認せず警告します。
- スクリプト内のコメントも能力語として検出するため、所見の文脈確認が必要です。
- `CLEAR`でも安全性は保証されません。
- VirusTotalなどの外部評価、複数アンチウイルスエンジン、クラウド上の既知ハッシュ、動的サンドボックスは含みません。用意しているのはSHA-256と照会URLのコピーまでで、照会そのものは操作者が別の場所で行います。

「NSA級」など外部機関の認証取得を意味する製品ではありません。ここでいう高強度化は、公開仕様に基づく多層防御と検証可能なフェイルクローズ設計を指します。

## 開発者向け

```powershell
dotnet build .\Destiny2BlackBox.csproj -c Release
```

CLI互換のレポート生成も用意しています。

```powershell
dotnet ".\bin\Release\net10.0-windows10.0.17763.0\PC Black Box.dll" --report "C:\path\to\target" ".\report.md"
```

ファイルを読み取らず、現在のセキュリティ基準だけを確認できます。

```powershell
dotnet ".\bin\Release\net10.0-windows10.0.17763.0\PC Black Box.dll" --security-status
```

外部プロセスからDACL、サイドチャネル緩和、通信アセンブリのFailFastをまとめて再検証できます。ローカルReleaseビルドのみを作成し、配布物は生成しません。

```powershell
pwsh -NoProfile -File .\tests\Test-RuntimeBoundaries.ps1
```

検索・絞込み・匿名化・セキュリティ基準を、対象ファイルなしで自己診断できます。一時レポートの作成・安全な置換・削除に加えて、自身で作成・削除する一時フォルダー内で調査経路そのもの（ハッシュの一致、スクリプト能力の検出、圧縮ファイルを展開せずに逸脱パスを報告すること、中止済みの調査が対象を読まないこと）も確認します。

```powershell
dotnet ".\bin\Release\net10.0-windows10.0.17763.0\PC Black Box.dll" --self-test
```
