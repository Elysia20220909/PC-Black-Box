# PC Black Box

ダウンロードしたファイルやフォルダーを、実行せずに調べるWindows向け静的調査ツールです。

Marathon Network Blockerの一画面で状態を読み取れる操作感を受け継ぎ、黒・白・黄を基調にしています。管理者権限は要求しません。

## 使い方

1. `PC Black Box.exe`を起動します。
2. ファイルまたはフォルダーを画面へドロップします。選択ボタンも利用できます。
3. `調査開始`を押します。
4. `概要`で主な所見、`ファイル`で個別情報、`レポート`で匿名化された報告書を確認します。

`JA / EN`で日本語と英語を切り替えられます。選択した言語だけが `%LOCALAPPDATA%\PCBlackBox\settings.json` に保存されます。

## 調べるもの

- SHA-256
- Authenticode署名と署名者
- Mark-of-the-Web（Internet Zone）と入手元ホスト名
- マジックバイトから見た実ファイル形式
- 二重拡張子、右から左への表示制御、拡張子偽装
- PEアーキテクチャ、製品名、会社名、エントロピー
- スクリプトやバイナリに見えるダウンロード、永続化、Defender設定変更、プロセス注入、削除などの能力語
- ZIP／Officeパッケージ内の実行要素、マクロ、パストラバーサル、極端な圧縮率

フォルダー調査は安全のため2,500ファイルまたは12GB、ZIP内部は10,000項目、署名確認は300ファイルで打ち切ります。リパースポイントは追跡しません。

## 判定について

`CLEAR / LOW / REVIEW / HIGH`は、確認の優先順位です。マルウェア判定や安全保証ではありません。

管理用スクリプト、インストーラー、圧縮ツールなどは正当な目的でも警告されることがあります。反対に、静的調査で兆候が見えない未知のコードもあります。署名、入手元、期待した用途、Windows Defenderなど複数の証拠を合わせて判断してください。

## プライバシーと安全境界

- 対象を起動しません。
- ファイルをアップロードしません。
- 自動的なネットワーク通信を行いません。
- プロセス注入、ゲームメモリ読み取り、パケット取得を行いません。
- ファイルの削除、隔離、移動、修復を行いません。
- レポートへ絶対パス、Windowsユーザー名、IPアドレス、Steam ID、認証情報を出しません。
- `ハッシュ照会を開く`は確認後にVirusTotalをブラウザーで開きます。送るのはURL中のSHA-256だけで、ファイル本体は送りません。

## 現在の制約

- 動的挙動、サンドボックス実行、通信先の実測は行いません。
- 7-Zip／RARは形式識別までで、内部展開はしません。
- スクリプト内のコメントも能力語として検出するため、所見の文脈確認が必要です。
- `CLEAR`でも安全性は保証されません。

## 開発者向け

```powershell
dotnet build .\Destiny2BlackBox.csproj -c Release
```

CLI互換のレポート生成も用意しています。

```powershell
dotnet ".\bin\Release\net10.0-windows10.0.17763.0\PC Black Box.dll" --report "C:\path\to\target" ".\report.md"
```
