## リポジトリ保存用のスクリプトで確認したこと

`tools/New-GuiValidation.ps1` と `tools/Start-GuiValidation.ps1` に移し、個人用の絶対パスと固定の起動場所を引数へ置き換えた。対象ソースSHAと検証済みDLLのハッシュを明示し、作業ツリーの変更有無をmanifestへ記録する。製品コードは変更していない。

- 移行中に構文エラーを検出し修正。修正後は両スクリプトの構文解析に成功。
- 新しい検証先で準備を実行し、16ファイルの照合に成功。
- 既存版22ファイルと共有設定は変更なし。
- `-Launch` なしの実行は照合だけで終了。
- 同じRunIdの再実行は上書きせず拒否。
- ハッシュ取得関数を呼び出し内だけ不一致値にする負の対照で、入力不一致として停止。実ファイルは改変していない。
- 対象ソースSHAの不一致、DLLハッシュの不一致は、検証フォルダーを作る前に拒否。
- 元のローカル専用検証構成も再照合に成功。個人の絶対パスや代表的な秘密情報パターンを新規4ファイルに限定して確認し、該当なし。
- 独立レビューでコピー中のDLL変化と旧版／出力先の包含関係の2件を指摘され、修正。旧版配下への出力を、書き込み前に拒否することを確認。
- DLLの初回事前照合とコピー時で異なるハッシュを返す負の対照で、指定したDLLから変化した場合に停止することを確認。実DLLは改変していない。テスト補助関数の変数スコープの誤りを修正して再実行した。
- 修正後の通常準備と16ファイルの非GUI照合も成功。失敗途中のテスト構成はGit管理外に保持し、完成した構成とは区別した。
- 独立した再レビューで2件の解消を確認し、追加の重大・中程度の指摘なし。構文解析、文書リンク、差分の空白検査を確認。ステージ済み差分のGitleaks検査は検出なし。
